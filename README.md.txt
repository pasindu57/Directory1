# BODIMA – Sri Lanka's Accommodation Directory (Demo)

A fully interactive, frontend-only accommodation directory. No backend is used.

## Run
1. Download/extract the folder.
2. Open `index.html` in a browser (or use VS Code "Live Server" for best experience).
3. Internet is required for Unsplash images, Google Fonts and Font Awesome.
4. All demo data (users, listings, favorites) persists in your browser's LocalStorage.

## Demo Notes
- Authentication is a frontend demo only — it is NOT secure and not connected to any server.
- Properties you submit are marked "Pending Approval" and appear in the directory immediately.
- WhatsApp / call buttons open real wa.me / tel links using the demo numbers in the data.
